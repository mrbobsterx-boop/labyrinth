# ЛАБИРИНТ — выживание в лабиринте (Roblox)

Кооперативная игра на выживание до 8 игроков.

## Как играть
1. **Лобби.** Зайди в лифт. Через 10 секунд он поедет со всеми, кто внутри.
2. **Поляна.** Безопасная зона в центре: лес, река с мостом, кусты с ягодами, костёр, верстак и ящик с начальными ресурсами. Вокруг огромные стены с четырьмя воротами.
3. **День (5 минут).** Ворота открыты. Исследуй лабиринт: шахты с камнем, железом и кристаллами, сундуки.
4. **Закат.** Ворота закрываются. Успей вернуться на поляну!
5. **Ночь (2,5 минуты).** В лабиринте бродят **Скрежетники**: сильные, быстрые, видят и слышат бег. На поляну они не заходят.
6. **Цель.** Найди **Ключ Лабиринта** в золотом сундуке в самом дальнем тупике, потом найди **выход**. Лабиринт каждый раз генерируется заново.

## Добыча и крафт
| Ресурс | Чем добывать |
|---|---|
| Дерево | топор |
| Камень | кирка ур. 1 |
| Железо | кирка ур. 2 (каменная) |
| Кристалл | кирка ур. 3 (железная) |
| Клык Скрежетника | победить монстра |

Верстак 1 уровня: факел, каменные кирка и топор, копьё, каменный меч, улучшение верстака.
Верстак 2 уровня: железная кирка, железный меч, кристальный клинок.

## Управление
ЛКМ — удар/добыча · 1–9 — предмет · Q — убрать · Shift — бег · H — съесть ягоды · E — действие.

Тестовые кнопки (справа вверху, `Config.DevTools = true`): курсор (M), полный свет (L), полёт (N), смена дня/ночи, ресурсы, телепорт к выходу. **Перед публикацией поставь `DevTools = false`.**

## Как открыть
Файл `build/Labyrinth.rbxlx` → Roblox Studio → File → Open from File → Play.
