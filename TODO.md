# Отложено / уточнить

- **Лифт «летающий»:** уточнить, что именно не так.
- **Музыка:** если какой-то трек не играет — заменить ID в `Config.Music.Playlist` на трек из Toolbox → Audio.
- **Консоль:** управление для геймпада — потом.
- ID классов (`runner`, `lumber`, `miner`, `warrior`) никогда не менять — иначе купленные классы пропадут.

Сделано: настройки, админ-панель (2436 — главная, 6363 — для друзей), невидимость, наблюдение, ТП к игроку,
ядерка, цунами, денежный дождь, надёжные сохранения, предметы в руке, броня, управление для телефона и планшета.
