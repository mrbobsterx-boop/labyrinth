# Следующие обновления (по очереди)

1. **Языки:** выбор языка при входе — русский, английский, немецкий, украинский, турецкий. Свой перевод всех надписей.
2. **Апдейт-пати:** два лифта справа от магазина → отдельная арена с мини-играми (во время админ-абьюза).
   (Сам админ-абьюз уже сделан: сообщение, монеты, Скрежетник в лобби, класс «Строитель» — на всех серверах.)
3. **Шахта-подземелье:** вход в шахту, темно, ставишь факелы; чем глубже — тем лучше руда, кристаллы на самом дне.
4. **Печь + уголь:** печь крафтится из камня; новая руда «уголь»; топливо — дерево или уголь (уголь лучше); переплавка железной руды.
5. **Перехват управления** игрока, за которым наблюдаешь (только ходьба и удар).
- **Музыка:** если какой-то трек не играет — заменить ID в `Config.Music.Playlist`.
- ID классов (`runner`, `lumber`, `miner`, `warrior`, `builder`) никогда не менять.
